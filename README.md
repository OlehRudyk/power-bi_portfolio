# power-bi_portfolio
# 📊 Power BI & Business Intelligence Portfolio

## 🎯 Про репозиторій (About)
Цей репозиторій містить колекцію аналітичних проєктів та інтерактивних дашбордів, розроблених у Microsoft Power BI. 

Як незалежний консультант із глибоким практичним досвідом у моніторингу та оцінці (M&E) й архітектурі збору даних, я спеціалізуюся на перетворенні складних "сирих" масивів інформації на зрозумілі, дієві візуалізації. Представлені проєкти демонструють повний цикл аналітики: від очищення даних (ETL) та побудови реляційних моделей до написання DAX-запитів і розробки інтуїтивно зрозумілого інтерфейсу користувача (UI/UX).

Головна мета цих дашбордів — виявити приховані закономірності (insights) та забезпечити надійне підґрунтя для прийняття стратегічних рішень.

## 📂 Портфоліо проєктів (Featured Projects)

### 1. Теплова карта інтенсивності обстрілів України (Geospatial Security Analysis)
![Обкладинка проєкту](https://github.com/OlehRudyk/power-bi_portfolio/blob/main/count_attack_Ukraine.png)

**Опис проєкту:** 
Аналітичний дашборд, що візуалізує щільність та інтенсивність повітряних атак по регіонах України. Проєкт розроблено для швидкого моніторингу безпекової ситуації з чітким зонуванням відносно безпечних та критичних територій.

**Використані інструменти та техніки:**
*   **Shape Maps (Карти фігур):** Використання векторних TopoJSON-файлів для створення ідеально чітких кордонів без візуального шуму стандартних карт.
*   **Custom Conditional Formatting:** Налаштування складної математичної логіки градієнта для коректного відображення статистичних викидів (величезної різниці між прифронтовими та тиловими областями).
*   **Data Bars & Cross-highlighting:** Інтеграція гістограм безпосередньо в табличну матрицю з налаштуванням динамічного перехресного підсвічування при взаємодії з картою.

### 2. Corporate Sales Performance Dashboard
![Обкладинка проєкту](https://github.com/OlehRudyk/power-bi_portfolio/blob/main/%D0%B4%D0%B0%D1%88%D0%B1%D0%BE%D1%80%D0%B4%20%D0%BF%D1%80%D0%BE%D0%B4%D0%B0%D0%B6.png)

**Опис проєкту:** 
Комплексний корпоративний звіт, який дозволяє зацікавленим сторонам відстежувати глобальні показники продажів, аналізувати прибутковість продуктових лінійок та моніторити розподіл доходів за регіонами та сегментами.

**Використані інструменти та техніки:**
*   **Data Modeling:** Проєктування реляційної моделі даних (Star Schema), налаштування зв'язків між таблицями фактів і вимірів.
*   **Power Query (ETL):** Очищення, трансформація та підготовка вихідних масивів даних.
*   **DAX (Data Analysis Expressions):** Розробка користувацьких мір (Measures) для розрахунку Gross Sales, Profit Ratio та показників Time Intelligence.
*   **Data Visualization:** Використання KPI-карток, комбінованих діаграм (Combo Charts) для трендів та Treemap для географічного розподілу.

### 3. E-commerce Root Cause Analysis
![Обкладинка проєкту](https://github.com/OlehRudyk/power-bi_portfolio/blob/main/%D0%B4%D0%B0%D1%88%D0%B1%D0%BE%D1%80%D0%B4%20%D0%BF%D1%80%D0%BE%D0%B4%D0%B0%D0%B6%20%D1%96%D0%BD%D1%82%D0%B5%D1%80%D0%BD%D0%B5%D1%82%20%D0%BC%D0%B0%D0%B3%D0%B0%D0%B7%D0%B8%D0%BD%D1%83.png)

**Опис проєкту:** 
Глибокий аналіз факторів, що формують загальний обсяг продажів інтернет-магазину. Дашборд дозволяє миттєво розкласти головний показник на складові (міста, типи клієнтів, стать, продуктові категорії), щоб знайти першопричини падіння чи зростання прибутку.

**Використані інструменти та техніки:**
*   **AI Visuals (Decomposition Tree):** Застосування дерева декомпозиції для інтерактивного та багатовимірного дослідження метрик.
*   **Root Cause Analysis:** Використання алгоритмів Power BI для автоматичного пошуку найвищих та найнижчих значень у розрізі обраних параметрів.

### 4. Макроекономічні тренди: Global GDP vs CO2 Emissions
![Обкладинка проєкту](https://github.com/OlehRudyk/power-bi_portfolio/blob/main/%D0%B2%D0%B0%D0%BB%D0%BE%D0%B2%D0%B8%D0%B9%20%D0%BF%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%82%20%D0%BA%D1%80%D0%B0%D1%97%D0%BD.png)

**Опис проєкту:** 
Анімована візуалізація макроекономічних показників у часі, що досліджує історичну кореляцію між економічним зростанням (ВВП на душу населення) та обсягами викидів CO2 за континентами та країнами.

**Використані інструменти та техніки:**
*   **Animated Scatter Plots:** Створення точкових діаграм з бульбашками, розмір яких залежить від популяції.
*   **Play Axis (Вісь відтворення):** Налаштування динамічної анімації по роках для відстеження еволюції показників у часовому вимірі.
