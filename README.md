# 📊 Power BI & Business Intelligence Portfolio

## 🎯 About This Repository
This repository contains a collection of analytical projects and interactive dashboards developed in Microsoft Power BI. 

As an independent consultant with deep practical experience in Monitoring and Evaluation (M&E) and data collection architecture, I specialize in transforming complex "raw" datasets into clear, actionable visualizations. The featured projects demonstrate the full analytics lifecycle: from data cleaning (ETL) and building relational models to writing DAX queries and designing intuitive user interfaces (UI/UX).

The primary goal of these dashboards is to uncover hidden insights and provide a reliable foundation for strategic decision-making.

## 📂 Featured Projects

### 1. Ukraine Shelling Intensity Heatmap (Geospatial Security Analysis)
![Project cover](https://github.com/OlehRudyk/power-bi_portfolio/blob/main/count_attack_Ukraine.png))

**Project Description:** 
An analytical dashboard visualizing the density and intensity of air attacks across regions of Ukraine. The project was developed for rapid monitoring of the security situation with clear zoning of relatively safe and critical territories.

**Tools & Techniques Used:**
*   **Shape Maps:** Utilizing vector TopoJSON files to create perfectly clear borders without the visual noise of standard maps.
*   **Custom Conditional Formatting:** Configuring complex mathematical gradient logic to correctly display statistical outliers (the vast difference between frontline and rear regions).
*   **Data Bars & Cross-highlighting:** Integrating data bars directly into a table matrix with dynamic cross-highlighting configured for interactions with the map.

### 2. Corporate Sales Performance Dashboard
![Project Cover](https://github.com/OlehRudyk/power-bi_portfolio/blob/main/%D0%B4%D0%B0%D1%88%D0%B1%D0%BE%D1%80%D0%B4%20%D0%BF%D1%80%D0%BE%D0%B4%D0%B0%D0%B6.png)

**Project Description:** 
A comprehensive corporate report that allows stakeholders to track global sales metrics, analyze the profitability of product lines, and monitor revenue distribution across regions and segments.

**Tools & Techniques Used:**
*   **Data Modeling:** Designing a relational data model (Star Schema), configuring relationships between fact and dimension tables.
*   **Power Query (ETL):** Cleaning, transforming, and preparing raw datasets.
*   **DAX (Data Analysis Expressions):** Developing custom measures to calculate Gross Sales, Profit Ratio, and Time Intelligence metrics.
*   **Data Visualization:** Utilizing KPI cards, Combo Charts for trends, and Treemaps for geographical distribution.

### 3. E-commerce Root Cause Analysis
![Project Cover](https://github.com/OlehRudyk/power-bi_portfolio/blob/main/%D0%B4%D0%B0%D1%88%D0%B1%D0%BE%D1%80%D0%B4%20%D0%BF%D1%80%D0%BE%D0%B4%D0%B0%D0%B6%20%D1%96%D0%BD%D1%82%D0%B5%D1%80%D0%BD%D0%B5%D1%82%20%D0%BC%D0%B0%D0%B3%D0%B0%D0%B7%D0%B8%D0%BD%D1%83.png)


**Project Description:** 
An in-depth analysis of factors driving total e-commerce sales. The dashboard allows for the instant breakdown of the main metric into its components (cities, customer types, gender, product categories) to find the root causes of profit decline or growth.

**Tools & Techniques Used:**
*   **AI Visuals (Decomposition Tree):** Applying a decomposition tree for interactive and multi-dimensional metric exploration.
*   **Root Cause Analysis:** Utilizing Power BI algorithms to automatically find the highest and lowest values across selected parameters.

### 4. Macroeconomic Trends: Global GDP vs CO2 Emissions
![Project Cover](https://github.com/OlehRudyk/power-bi_portfolio/blob/main/%D0%B2%D0%B0%D0%BB%D0%BE%D0%B2%D0%B8%D0%B9%20%D0%BF%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%82%20%D0%BA%D1%80%D0%B0%D1%97%D0%BD.png)

**Project Description:** 
An animated visualization of macroeconomic indicators over time, exploring the historical correlation between economic growth (GDP per capita) and CO2 emissions across continents and countries.

**Tools & Techniques Used:**
*   **Animated Scatter Plots:** Creating bubble scatter plots where bubble size depends on population.
*   **Play Axis:** Configuring dynamic year-over-year animation to track the evolution of indicators over time.
